왜 확인했는가?

0.242QD 평균 ρ / Batch 1
0.117QD 평균 ρ / Batch 2

핵심 발견

3.3 Question 3 / Core Analysis

ΔQ(V)는 초기 100 Cycle 안에서
수명 차이를 포착했다

ΔQ(V)는 무엇인가?

Cycle 10과 cycle 100에서 같은 전압을 비교했을 때 방전 가능한 용량이 얼마나 달라졌는지를 나타낸다.

ΔQ(V) = Q100(V) - Q10(V)

왜 확인했는가?

초기 Capacity 절대값의 차이가 작았기 때문에 “얼마나 큰가”보다 전압별 방전곡선의 변화 형태가 수명을 설명하는지 확인했다.

어떻게 확인했는가?

실제 cycle 10·100의 Qdlin을 공통 전압축에서 빼고, 각 Batch 수명 상·하위 25%의 중앙곡선과 IQR을 비교했다.

Figure 3. 장수명·단수명 그룹의 ΔQ(V) 곡선

이 그림에서 볼 것 단수명 그룹은 장수명 그룹보다 cycle 10→100 사이의 방전곡선 변화 폭이 크다. 이 차이는 특정 Batch에만 나타나지 않고 세 Batch에서 같은 방향으로 관찰된다.

Capacity Level

초기 QD 평균은 배치 안에서 수명과의 관계가 약했다.

Change Shape

ΔQ(V)는 눈에 잘 보이지 않는 초기 열화 차이를 전압 구간별 형태로 드러냈다.

다음 근거 곡선 차이가 “보이는 것”에서 끝나지 않도록, ΔQ(V) 변화의 크기를 로그분산으로 요약해 Cycle Life와의 관계를 Batch별로 확인했다.

3.4 Question 4

빠른 충전 하나만으로
수명을 설명할 수 없었다

왜 확인했는가?

충전 속도는 열화에 영향을 줄 수 있으므로 Charging Policy가 수명 차이를 추가로 설명하는지 확인했다.

어떻게 확인했는가?

정책 문자열을 1단계 C-rate·전환 SOC·2단계 C-rate로 나누고, 산점도와 정책별 평균·표본 수·bootstrap 95% 신뢰구간을 비교했다.

C-rate는 배터리 용량 대비 충전 전류의 크기로, 값이 클수록 더 빠르게 충전한다는 뜻이다.

Figure 5. 충전 조건과 Cycle Life의 관계

이 그림에서 볼 것 같은 C-rate에서도 수명이 넓게 퍼지고 정책별 평균의 불확실성도 크다. “빠른 충전 = 짧은 수명”이라는 하나의 직선 규칙으로 설명하기 어렵다.
범위1단계 C-rate ρ판단
전체-0.027사실상 관계 없음
Batch 1-0.483음의 관계
Batch 20.055방향이 뒤집히며 매우 약함
Batch 3-0.229음의 방향이지만 약함
핵심 발견

Batch 1의 음의 관계는 Batch 2·3에서 같은 크기로 반복되지 않았다. 일부 정책은 n=1~2라 평균 수명의 불확실성도 크다.

해석

6. 왜 Regression인가?

“긴가, 짧은가”보다
“몇 Cycle인가”를 예측한다

Classification

범주를 맞춘다

장수명 / 단수명처럼 정해진 등급 중 하나를 예측

Regression

숫자를 맞춘다

처음부터 EOL까지 총 몇 cycle인지 연속값으로 예측

왜 수명 숫자가 필요한가? ESS 유지보수와 교체 시점을 정량적으로 판단하려면 “긴가, 짧은가”보다 “몇 cycle인가”가 더 직접적인 정보다. Target을 연속형 cycle_life로 두는 Regression을 선택한다.

Primary Metric - MAPE

Meaning

MAPE는 예측 오차를 실제 수명 대비 백분율로 나타낸다.

예: MAPE 10%라면 평균적으로 실제 수명의 약 10% 정도를 벗어났다는 뜻이다.

Benchmark

원논문 테스트 오차 9.1%

성능을 가늠하는 참고값이며, 현재 전처리·Feature·split이 완전히 같지 않으므로 동일 조건 재현이라고 표현하지 않는다.

7.1 데이터 특성이 말해주는 모델 조건

Small Sample

독립 Sample은 Cycle이 아니라 Cell이며 Batch 1은 46개다.

High Redundancy

ΔQ 파생변수와 온도 Feature는 서로 비슷한 정보가 많다.

Possible Nonlinearity

ΔQ와 수명의 관계가 강해도 완전히 선형이라고 보장할 수 없다.

Uncertain Incremental Value

Sensor와 Charging이 ΔQ에 추가 정보를 주는지는 아직 불확실하다.

모델 비교 원칙 복잡한 모델 하나를 바로 선택하지 않고, 단순 baseline부터 규제 선형모델과 비선형 모델을 동일한 검증 조건에서 비교한다.
